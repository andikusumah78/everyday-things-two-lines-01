# Everyday Things, Two Lines, Longer Run

Entry for the make.fun bounty
[Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

`main.py` (pure Python stdlib, deterministic, no network) writes a two-line
explanation of a queue — as a caterpillar made of people — to
`/output/entry.txt`. Line 1 explains the everyday thing with a vivid analogy
for a 10-year-old; line 2 says honestly what the analogy maps and what it
leaves out.
